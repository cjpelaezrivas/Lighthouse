Include configuration from nested YAML

Getting variable values from external YAML config files:

  • value 1
  • value 1.1
  • value 1.2
  • value 2
  • value 3
  • value 4

Success - Variables set before using can be found:

  • Variable value found

Error - Variables used before setting can not be found:

  • ##ERROR - Variable not found: external_config_2.key_5##

Including YAML file as String:

key_1: value 1 key_2: value 2 subconfig: "key_1_1: value 1.1 key_1_2: value 1.2 key_1_3: "Variable value found" key_1_4: "value 5""

Note: Notice it finds external_config.subconfig.key_1_4 here, because the tag is replaced after configuration was processed
